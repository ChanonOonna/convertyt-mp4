# YouTube Downloader

โปรแกรม Desktop สำหรับโหลดวิดีโอ / เสียงจากลิงก์ YouTube เป็น MP4 (1080p / 720p / 480p) หรือ MP3

## ติดตั้ง

ต้องใช้ Windows 10/11 และอินเทอร์เน็ต ไม่ต้องติดตั้ง Python เอง (โปรแกรมจะติดตั้งให้ถ้ายังไม่มี)

1. ดาวน์โหลดโปรเจกต์ วางไว้ที่ไหนก็ได้
   - กด **Code → Download ZIP** บนหน้านี้ แล้วแตกไฟล์ หรือ
   - `git clone https://github.com/ChanonOonna/convertyt-mp4.git`
2. ดับเบิลคลิก `convert_link_youtube_to_mp4.bat` — ครั้งแรกจะติดตั้งส่วนประกอบทั้งหมดให้เอง (1-3 นาที)
   - ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
3. ครั้งต่อไปเปิดจากชอร์ตคัต **Convert Link YouTube to MP4** บนเดสก์ท็อป (สร้างให้อัตโนมัติ)

อัปเดตเป็นเวอร์ชันใหม่: `git pull` (หรือดาวน์โหลด ZIP ใหม่แตกทับ) — การตั้งค่าเดิมไม่หาย

## วิธีใช้

1. เปิดโปรแกรม (ชอร์ตคัตบนเดสก์ท็อป หรือ `convert_link_youtube_to_mp4.bat`)
2. หน้าต่าง **ตรวจสอบระบบ** จะเช็กทุกอย่างก่อน แล้วติดตั้ง/อัปเดตสิ่งที่ขาดให้เอง (ดูหัวข้อถัดไป)
   - ระบบพร้อม → เปิดหน้าโปรแกรมให้อัตโนมัติ
   - มีคำเตือน → แสดงรายการที่มีเครื่องหมาย `!` แล้วเปิดโปรแกรมใน 6 วินาที
   - ยังไม่พร้อม → แสดงรายการที่มีเครื่องหมาย `✗` พร้อมปุ่ม "ลองใหม่" / "เปิด error.log"
3. วางลิงก์ YouTube ในช่องด้านบน แล้วกด **Enter**
   - วางลิงก์วิดีโอ, ลิงก์เพลย์ลิสต์ หรือหลายลิงก์พร้อมกันก็ได้
   - รายการใส่ได้ **สูงสุด 50 รายการ** (เพลย์ลิสต์ที่ยาวกว่านั้นจะดึงมาแค่ส่วนที่ใส่ได้)
4. แต่ละรายการเลือกได้ว่าจะโหลดเป็น `MP4 1080p` / `MP4 720p` / `MP4 480p` / `MP3`
   - หรือใช้ "ทุกรายการ:" เพื่อเปลี่ยนทุกรายการพร้อมกัน
5. กดปุ่ม **ดาวน์โหลดทั้งหมด** ด้านล่าง (กดซ้ำระหว่างโหลดเพื่อหยุด)

ไฟล์จะถูกบันทึกที่ `Downloads\YouTube Downloads` (กด "เปลี่ยน…" เพื่อเลือกโฟลเดอร์อื่น โปรแกรมจะจำไว้)

## การแจ้งเตือนข้อผิดพลาด

- **แถบแจ้งเตือน** ใต้ช่องลิงก์: ลิงก์ไม่ถูกต้อง, ดึงข้อมูลไม่สำเร็จ, รายการเต็ม 50, เพลย์ลิสต์ยาวเกิน, เปิดโฟลเดอร์ไม่ได้
- **หน้าต่างสรุป** เมื่อโหลดเสร็จแล้วมีบางรายการไม่สำเร็จ: บอกชื่อคลิปและสาเหตุ (เช่น วิดีโอส่วนตัว, 403, พื้นที่ดิสก์เต็ม)
- **หน้าต่าง error** เมื่อโปรแกรมเจอข้อผิดพลาดที่ไม่คาดคิด (bug) — โปรแกรมยังใช้ต่อได้
- ทุกข้อผิดพลาดถูกบันทึกพร้อมรายละเอียดใน `error.log`

### วิธีการเบื้องหลัง

- **ดึงรายการให้เร็ว:** ใช้โหมด `extract_flat` ของ yt-dlp ดึงแค่ข้อมูลสรุปของแต่ละคลิป ไม่ต้องดึงข้อมูลเต็ม เพลย์ลิสต์ยาวจึงขึ้นภายในไม่กี่วินาที และดึงไม่เกิน 50 คลิป (`playlistend`)
- **เลือกความละเอียด:** ใช้ `format_sort` จัดลำดับความสำคัญ = ความละเอียดสูงสุดที่ไม่เกินที่เลือก → ภาพ H.264 → เสียง AAC จึงได้ MP4 ที่เปิดได้ทุกเครื่อง ถ้าคลิปไม่มีความละเอียดนั้นจะได้ระดับที่ต่ำกว่า และชื่อไฟล์บอกความละเอียดจริง เช่น `ชื่อคลิป (720p).mp4`
- **รวมภาพกับเสียง:** ตั้งแต่ 720p ขึ้นไป YouTube ส่งไฟล์ภาพกับเสียงแยกกัน (DASH) โปรแกรมจึงโหลดทั้งสองไฟล์แล้วให้ FFmpeg รวม แถบความคืบหน้าคิดจากขนาดของทั้งสองไฟล์รวมกัน จึงวิ่ง 0→100% ครั้งเดียว
- **หน้าจอไม่ค้าง:** งานดาวน์โหลดทำในเธรดเบื้องหลัง (`ThreadPoolExecutor`) พร้อมกันครั้งละ 2 รายการ แล้วส่งความคืบหน้ากลับมาที่หน้าจอผ่านคิว เพราะ tkinter ให้แก้หน้าจอได้จากเธรดหลักเท่านั้น
- **รายการเร็ว:** แถวรายการใช้ tkinter ธรรมดาแทน CustomTkinter ซึ่งวาดทุกอย่างบน canvas เร็วขึ้นราว 6 เท่าต่อแถว
- **อัปเดตตัวเอง:** ทุกครั้งที่เปิด หน้าตรวจระบบเทียบเวอร์ชัน yt-dlp กับเวอร์ชันล่าสุดบน PyPI แล้วอัปเดตให้ เพราะ YouTube เปลี่ยนระบบบ่อย
- **ข้อความ error ภาษาไทย:** แปลงข้อความ error ภาษาอังกฤษจาก yt-dlp มากกว่า 20 แบบเป็นภาษาไทย เช่น `HTTP Error 403` → "YouTube ปฏิเสธการดาวน์โหลด (403)…"
- **คีย์ลัดใช้ได้ทุกภาษา:** Ctrl+V / A / C / X ตรวจจากรหัสปุ่มจริง (keycode) จึงใช้ได้แม้เปิดแป้นภาษาไทย

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `convert_link_youtube_to_mp4.bat` | ตัวเปิดโปรแกรม: หา/ติดตั้ง Python, สร้าง `.venv`, แล้วเปิด `main.py` |
| `main.py` | จุดเริ่ม: ตรวจสอบระบบ แล้วเปิดหน้าโปรแกรม |

| `settings.json` | โฟลเดอร์ปลายทาง / รูปแบบล่าสุดที่เลือก (สร้างอัตโนมัติ) |
